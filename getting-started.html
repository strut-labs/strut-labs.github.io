Getting started

After downloading Strut 0.0.1 or building it from source, the simplest workflow is one source file and one command.

Your first program

function main() -> int {
    print("hello, world!");
    return 0;
}

Executable entry points return a process exit status. Use main(string[] args) when you need command-line arguments; args contains only user arguments, while program_path() returns the executable path.

Compile it

strut hello.p

The default output is a native executable named from the source file. Use -o when you want to choose the path explicitly.

strut hello.p -o hello
./hello

Check source without linking

strut --check hello.p

From here, the syntax and types pages are the shortest path through the implemented language surface.
