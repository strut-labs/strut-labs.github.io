Getting started

Early implementation: Strut is being built checkpoint-by-checkpoint. Syntax documented here is the current language contract; not every feature is implemented yet.

Build the bootstrap compiler

cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Debug
cmake --build build
ctest --test-dir build --output-on-failure

The shape of a program

function main() -> void {
    x := 2;
    y := 3;
    out << x + y << endl;
    return;
}

Ordinary variables are mutable. Use const when immutability matters. Statements end in semicolons.
