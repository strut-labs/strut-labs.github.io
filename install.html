Install & build

The bootstrap compiler uses portable C++20 and CMake. Linux is the initial development host, while macOS and Windows remain first-class architectural targets.

Requirements

  • CMake 3.20+
  • GCC, Clang, Apple Clang, or MSVC with C++20 support
  • Ninja is recommended but optional

Current build

cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
