A concise, memory-safe compiled language

Build with
support.

Strut combines native compilation, deterministic memory management, concurrency, and a growing native backend stack: HTTP/TLS, streaming, SQLite, full-duplex WebSockets, subprocesses, crypto, cancellation, and cross-platform PTYs including Windows ConPTY.
