Editor & language server

Strut ships its language server with the compiler. Editors communicate with strut lsp over standard JSON-RPC/LSP on stdin and stdout, so editor support does not depend on a separate language-analysis implementation.

Start the language server

strut lsp

Diagnostics

The language server reuses Strut's lexer, parser, semantic analyser, and source spans. Syntax and type errors therefore match command-line diagnostics rather than being reimplemented by an editor plugin.

Navigation and assistance

The current server provides document diagnostics, go-to-definition, completion, hover/type information, and document formatting. Formatting uses the same canonical formatter as strut fmt.

Editor integration

Configure an editor's generic LSP client to launch strut lsp for .p and .h files. A dedicated editor extension can add convenience later without changing the protocol.
