Generics

Generic declarations use square brackets so they do not collide visually with instantiated types and callable signatures.

function max[T](T a, T b) -> T {
    return a > b ? a : b;
}

Template identifiers are uppercase. Typed lambdas may infer otherwise-undeclared uppercase type parameters:

max := (T x, T y) => x > y ? x : y;
