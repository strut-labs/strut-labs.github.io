Async

Strut supports async functions, futures, await, and async lambdas. The current bootstrap uses native asynchronous tasks; the dedicated multithreaded Strut executor is the next concurrency checkpoint.

Async functions

Prefix a function declaration with async. Calling it returns a future for the declared result type.

async function answer() -> int {
    return 42;
}

Awaiting a result

function main() -> void {
    pending := answer();
    value := await pending;
    print(value);
    return;
}

Async lambdas

Async lambdas use the same lambda syntax with an async prefix.

add := async (int x, int y) => x + y;

Async block lambdas

load := async (string path) => {
    print("loading " + path);
    return path;
};

Error propagation

Errors raised by asynchronous work are retained by the future and surface when the result is awaited.
