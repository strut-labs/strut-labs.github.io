CLI

The primary single-file workflow is intentionally direct: pass a Strut source file to strut and receive a native executable.

Compile one file

strut hello.p

Choose output path

strut hello.p -o hello

Check without producing an executable

strut --check hello.p

Inspect tokens

strut --tokens hello.p

Initialise project build state

strut init creates .strut/config.json without replacing an existing configuration. The file contains machine/project build settings such as the entrypoint, output path, target, build mode, linking default, and incremental mode. Generated object and dependency metadata elsewhere under .strut/ should not be source-controlled.

strut init

Persistent native objects

When a source file is the configured project entrypoint, Strut separates native compilation from linking and stores the native object under .strut/obj/<target>/<mode>/. Generated C++ used by the bootstrap backend is kept under .strut/gen/ for diagnostics. Removing these directories is always a safe clean rebuild path.

Dependency metadata

After a successful object build, Strut writes .strut/info/<target>/<mode>/<unit>.info.json. It records the source, object, local and package dependencies, compiler version, target, mode, and build fingerprint. Metadata is written only after the corresponding object file succeeds.

Incremental rebuilds

Strut compares each dependency recorded in a unit’s .info.json with the metadata timestamp. Missing objects/metadata, malformed metadata, changed dependency graphs, changed build fingerprints, missing dependencies, and dependency mtimes equal to or newer than the metadata force recompilation. Equal timestamps are deliberately treated as potentially stale, matching Nift’s conservative modified-mode rule.

Use --verbose to see whether an object is reused or why it is rebuilt.

strut src/main.p -o app --verbose

Project compilation

The project-level workflow is planned around strut make, keeping the single-file path short while still supporting packages, linking modes, and cross-platform builds.

strut make
