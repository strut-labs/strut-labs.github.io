CLI

The primary single-file workflow is intentionally direct: pass a Strut source file to strut and receive a native executable.

Compile one file

strut hello.p

Choose output path

strut hello.p -o hello

Check without producing an executable

strut --check hello.p

Inspect tokens

strut --tokens hello.p

Project compilation

The project-level workflow is planned around strut make, keeping the single-file path short while still supporting packages, linking modes, and cross-platform builds.

strut make
