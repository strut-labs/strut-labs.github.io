Operators

Strut has a fixed, language-defined operator table. Packages may overload supported operators, but they cannot invent punctuation or change precedence, which keeps parsing predictable for people, formatters, and coding agents.

Overloadable operators

FormOperatorsOverloadableNotes
Infix arithmetic+ - * / %YesTwo parameters.
Infix comparison== != < <= > >=YesTwo parameters.
Infix logical/bitwise|| && | ^ &YesTwo parameters.
Infix shifts<< >>YesTwo parameters; << is also used by stream insertion overloads.
Prefix+ - ! ~ *YesOne parameter.
Postfix++ --YesOne parameter.
Assignment= :=Yes= updates an existing destination; := initializes new storage.
Null coalescing??NoLanguage-defined nullable semantics.
Index and call[] ()ReservedReserved overload points; source declarations are not enabled yet.

Arithmetic and comparison

total := price * quantity + shipping;
ready := total >= 100 && enabled;

Dereference

Prefix * dereferences a safe T* and remains overloadable for user-defined pointer-like types.

int* value := new(7);
print(*value);

Normal overload declarations

operator +(Vector a, Vector b) -> Vector {
    return Vector { x: a.x + b.x, y: a.y + b.y };
}

Generic operator overloads

operator[T] +(Vector<T> a, Vector<T> b) -> Vector<T> {
    return Vector<T> { x: a.x + b.x, y: a.y + b.y };
}

Lambda operator declarations

operator<(Vector, Vector) -> Vector> + :=
    (a, b) => Vector { x: a.x + b.x, y: a.y + b.y };

Assignment and initialization

= operates on an existing destination. := represents construction into new storage when an explicit destination type makes overload resolution meaningful.

operator =(Widget& dst, Widget& const src) -> Widget& {
    dst.value = src.value;
    return dst;
}
