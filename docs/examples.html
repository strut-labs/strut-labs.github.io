Examples

Small examples are kept deliberately ordinary. The point is to show how Strut reads in real code rather than compress every language feature into one demonstration.

Hello world

function main() -> void {
    print("hello, world!");
    return;
}

Collections

function main() -> void {
    int[] values := [1, 2, 3, 4];
    squares := values.map((x) => x * x);

    for (value : squares) {
        print(value);
    }

    return;
}

JSON configuration

config := {
    "host": "127.0.0.1",
    "port": 8080
};

print(json.pretty(config));

Safe pointers

ptr<int> value := ptr(7);
ptr<int> copy := value;
print(*copy);
