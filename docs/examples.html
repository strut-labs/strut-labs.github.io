Examples

Small examples are kept deliberately ordinary. The point is to show how Strut reads in real code rather than compress every language feature into one demonstration.

Hello world

function main() -> int {
    print("hello, world!");
    return 0;
}

Collections

function main() -> int {
    int[] values := [1, 2, 3, 4];
    squares := values.map((x) => x * x);

    for (value : squares) {
        print(value);
    }

    return 0;
}

JSON configuration

config := {
    "host": "127.0.0.1",
    "port": 8080
};

print(json.pretty(config));

Safe pointers

Raw extraction is explicit and limited to unsafe code. This complete example is compiled and executed by documentation CI:

function main() -> int {
    int* value := new(7);
    unsafe {
        raw_ptr<int> address := ptr(value);
        print(*address);
    }
    return 0;
}

Tuple and collections

include <tuple>;
include <map>;
include <priority_queue>;

tuple<double, int> measurement := (2.0, 1);
map<string, int> counts := ["ready": 2];

priority_queue<int, min> next;
next.push(8);
next.push(3);
print(next.top()); // 3

Filesystem scripting

include <filesystem>;

make_dir("dist/assets");
copy(["css/*.css", "js/*.js"], "dist/assets");
write_file("dist/version.txt", "0.0.3\n");

for (path : walk("dist")) {
    print(path);
}
