Filesystem, processes & environment

Strut's standard library provides direct access to environment variables, clocks, sleeping, and external programs. Process execution is argv-based by default: arguments are passed as arguments rather than interpolated into a shell command.

Read environment variables

env() returns a nullable string because a variable may not exist. Use ?? when a default is appropriate.

home := env("HOME") ?? "";
print(home);

Set and remove environment variables

Mutating the current process environment can fail and uses the checked EnvironmentError contract.

function main() -> void : EnvironmentError {
    set_env("STRUT_MODE", "development");
    print(env("STRUT_MODE") ?? "missing");
    unset_env("STRUT_MODE");
    return;
}

Clocks and durations

now_ms() is monotonic and is suitable for measuring elapsed time. unix_ms() reports milliseconds since the Unix epoch. sleep_ms() pauses the current thread.

before := now_ms();
sleep_ms(25);
after := now_ms();
print(after - before);

Run an external program

exec(program, args) launches the program directly and captures stdout and stderr. It returns an exec_result containing exit_code, stdout, and stderr.

result := exec("git", ["status", "--short"]);
print(result.exit_code);
print(result.stdout);

Working directory and environment overrides

An options object can set the child's working directory and add or replace environment variables without changing the argv-safe launch model.

result := exec("tool", ["input.txt"], {
    "cwd": "/tmp/work",
    "env": {
        "MODE": "test"
    }
});

Inherited standard streams

Set inherit_stdio when the child should use the parent's terminal or redirected streams instead of being captured.

result := exec("tool", [], {
    "inherit_stdio": true
});

Shell execution is explicit

Normal exec never requires shell interpolation. When shell syntax itself is intentionally required, use the visibly different exec_shell API.

result := exec_shell("printf 'hello\n'");

Prefer exec whenever possible, especially when any argument contains external or user-provided data.

Filesystem

Filesystem operations live in the explicit <filesystem> standard module and use checked FilesystemError failures.

include <filesystem>;

make_dir("build/assets");
copy("logo.png", "build/assets/logo.png");
move("old.txt", "archive/old.txt");
remove("scratch.txt");
remove_all("tmp");

Bulk paths

copy and move accept a vector of source paths and copy/move each source into an existing destination directory. remove and remove_all also accept vectors.

include <vector>;
include <filesystem>;

copy(["a.txt", "b.txt"], "backup");
move(["one.log", "two.log"], "archive");
remove(["a.tmp", "b.tmp"]);

Wildcards

Source operands support portable Strut-side *, ?, and recursive ** expansion. Destination paths never expand wildcards. Wildcard copy/move requires an existing destination directory; an unmatched copy/move is an error, while unmatched removal is a no-op.

copy("assets/*.png", "public/images");
move("logs/*.log", "archive");
remove("build/*.o");
remove_all("tmp/**");
copy(["css/*.css", "js/*.js"], "dist");

Metadata and traversal

ls(root) returns names directly below root. walk(root) returns recursive paths relative to root; pass join_path(root, entry) to metadata or IO operations.

print(exists("data.txt"));
print(is_file("data.txt"));
print(is_dir("assets"));
print(file_size("data.txt"));
print(modified("data.txt"));

entries := ls("assets");
all_entries := walk("assets");
first_path := join_path("assets", all_entries[0]);

Path operations

path := join_path("assets", "images", "logo.png");
print(absolute(path));
print(canonical(path));
print(parent(path));
print(filename(path));
print(extension(path));
print(stem(path));

Current directory

before := cwd();
cd("workspace");
print(cwd());
cd(before);

Removal semantics

remove() removes a file or empty directory. Recursive deletion is deliberately explicit through remove_all().
