Implementation status

This website describes current development APIs at compiler checkpoint d9e6c47. The latest tagged release is v0.0.3. Installation commands install the latest tagged release; APIs marked current-main or unreleased require a compiler built from development main.

Platform certification

The compiler and generated C++ are certified on Linux x64 with GCC and Clang, Linux ARM64 with GCC, macOS ARM64 with AppleClang, and Windows x64 with MSVC. The independent regression suite is green on Linux, macOS, and Windows. PTY behavior executes on Linux and macOS; P9 adds executable Windows ConPTY behavior, lifecycle, descendant, churn, and resource certification.

Current positioning

Current main has concrete building blocks for serious native backend and full-stack work: HTTP/TLS servers, strict request framing, streaming bodies, persistence, NDJSON, outbound HTTP, cancellation, crypto, SQLite, WebSockets, subprocesses, concurrency, and cross-platform PTYs. These capabilities have focused compiler, protocol, lifecycle, resource, and cross-platform certification. The project does not yet label the complete backend/runtime stack production-grade; broader production certification remains later campaign work.

Still deferred

HTTP/2, ACME/certificate automation, reverse-proxy trust automation, outbound WebSocket clients, WebSocket extensions such as permessage-deflate, and a centralized package registry remain unimplemented or deferred. WebSocket-to-PTY integration is intentionally outside P9 and has not begun.
