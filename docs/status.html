Implementation status

The docs describe both the language contract and the compiler as it exists today. This page is the quick reference for what has actually reached the implementation and regression suite.

Implemented through CP59

  • Portable C++17/CMake bootstrap, with Linux, macOS, and Windows treated as first-class architectural targets.
  • Lexer, parser, semantic analysis, typed source-mapped IR, and native executable generation through a backend boundary.
  • Primitive and fixed-width types, ordinary type aliases, arrays, maps, strings, JSONIC-backed json, structs, generics, enums, switch, and exhaustive enum match.
  • First-class functions, generic and inferred lambdas, fixed-precedence operator overloading, lambda operator definitions, and overloadable assignment/initialisation.
  • No-GC memory model prototype with reference-counted ptr<T>, non-owning ref<T>, weak_ptr<T>, and explicit unsafe/raw_ptr<T>.
  • Checked error signatures, throw, typed try/catch, and catch-all handling.
  • Filesystem operations, istream/ostream//ifstream/ofstream, in/out/err, <</>>, and explicit file .open()/.close().
  • Environment access, monotonic and Unix clocks, millisecond sleeping, and safe argv-based external process execution.
  • exec captures stdout/stderr and exit status, supports inherited stdio, cwd and environment overrides, while exec_shell is the explicitly opt-in shell path.
  • Independent black-box regression coverage for compiler failures and generated native programs.

Next

CP60 starts the lower-level child-process and pipe API for long-lived subprocesses, streaming stdin/stdout/stderr, waiting, termination, and shell-free pipe composition.
