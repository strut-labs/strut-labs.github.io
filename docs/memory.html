Memory

Strut has no tracing garbage collector. Safe ownership is deterministic: ptr<T> uses reference counting, and the object is destroyed when the final owning pointer is released.

Safe owning pointers

ptr<User> user := ptr(User { id: 1, name: "Ada" });
ptr<User> second := user;

Const pointees and const bindings

ptr<const User> read_only := user;
const ptr<User> fixed_owner := user;

References

ref<T> is non-owning, non-null, and non-rebindable. Use it when a callee needs temporary access without reference-count churn.

function print_user(ref<const User> user) -> void {
    print(user.name);
}

Weak pointers

weak_ptr<User> weak := weak(user);
if (!weak.expired()) {
    ptr<User> locked := weak.lock();
}

Unsafe raw pointers

Raw pointers exist for FFI and specialised low-level work, but they are restricted to explicit unsafe regions. Member access supports the familiar raw->member form as well as explicit dereference when needed.

unsafe {
    raw_ptr<User> raw := raw(user);
    print(raw->name);
}

Reference cycles

Reference counting cannot automatically collect strong cycles. Use weak_ptr<T> for back-references. The compiler warns for obvious cycles it can identify statically.
