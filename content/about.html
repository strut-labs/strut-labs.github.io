What is Strut?

A concise route from intent to native code.

Strut pairs a structured type system and checked errors with owning safe pointers, explicit raw-pointer escape hatches, threads and atomics. Its compiler generates readable C++20 and invokes the platform toolchain to produce ordinary native binaries.

The project also ships the practical surroundings: packages, offline locks and caches, a language server, machine-readable API metadata, JSON, SQLite, networking, HTTPS, filesystem and process APIs.

Native by construction

A transparent compilation pipeline.

The compiler resolves and checks Strut source, selects the runtime components the program actually needs, then hands focused C++20 to the native toolchain. There is no bytecode VM and no hidden application server.

Conservative fallbacks preserve correctness for complex combinations while small programs stay small.

Controlled AI-DX benchmarks certify representative tasks and diagnostics. They are project tests—not claims that every model or workflow behaves identically.
