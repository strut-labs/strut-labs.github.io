About Strut

Support without bulk.

Strut is an experimental native compiled language shaped around memory safety, concise syntax, deterministic behaviour, agent-friendly code, and straightforward deployment. It borrows proven ideas from C++, Nift, Go, Rust, Zig and elsewhere without inheriting ceremony simply for familiarity.

Design target
memory safe
native performance
no garbage collector
real concurrency
small language surface
static + dynamic linking
cross-platform by design
