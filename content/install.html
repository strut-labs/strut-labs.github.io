Install & build

Strut is currently built from source. The compiler is portable C++ and is tested with GCC and Clang; Windows/MSVC remains a first-class architectural target.

Configure

cmake -S . -B build -G Ninja

Build

cmake --build build

Run compiler tests

ctest --test-dir build --output-on-failure

Compiler dependencies

JSONIC is embedded for Strut's built-in JSON implementation. libcurl is approved for HTTP/client TLS and OpenSSL is approved for server-side TLS work. Additional third-party components are not added implicitly.
