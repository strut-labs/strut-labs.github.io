Getting started

Strut currently builds from source while the compiler is under active development. Once the compiler is available, the simplest workflow is one source file and one command.

Your first program

function main() -> void {
    print("hello, world!");
    return;
}

Compile it

strut hello.p

The default output is a native executable named from the source file. Use -o when you want to choose the path explicitly.

strut hello.p -o hello
./hello

Check source without linking

strut --check hello.p

From here, the syntax and types pages are the shortest path through the implemented language surface.
