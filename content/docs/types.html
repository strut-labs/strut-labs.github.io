Types

Default numeric names are ordinary aliases rather than privileged compiler-only spellings.

type int := int_32;
type uint := uint_32;
type double := double_32;

Explicit widths include int_8 through int_64, unsigned equivalents, and double_32/double_64.

Dynamic arrays use T[]; fixed arrays use T[n]. Maps use map<K,V>, json is a built-in type, and user structs are now compiled types.

:= performs type inference, explicit numeric annotations are compatibility-checked, widening conversions are supported, and const assignment is rejected.

Nullability

Nullable values use T?. Safe member access uses ?., fallback/defaulting uses ??, and a successful value != null check narrows the value inside the guarded branch.
