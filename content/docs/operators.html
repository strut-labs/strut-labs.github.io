Operators

Strut uses a fixed language-defined operator set and precedence table. Supported operators can be overloaded; packages cannot invent new punctuation or alter parsing precedence.

operator +(Vector a, Vector b) -> Vector {
    ...
}

operator<(vector<int>, vector<int>) -> vector<int>> + :=
    (a, b) => { ... };

Assignment =, typed initialization :=, and prefix dereference * are intended to be overloadable where their semantics remain well-defined.
