Collections

Dynamic arrays, fixed arrays and maps are implemented, together with higher-order and query-style helpers.

int[] values := [1, 2, 3, 4];

doubled := values.map((x) => x * 2);
even := values.filter((x) => x % 2 == 0);
sum := values.reduce((a, b) => a + b);
found := values.find((x) => x == 3);
counts := values.count_by((x) => x % 2);
parts := values.partition((x) => x > 2);

map<string, int> scores := [
    "alice": 10,
    "bob": 20
];

Implemented helpers include map, filter, reduce, any, all, find, count, callback sorting, count_by, duplicate-rejecting index_by and partition. JSON objects also expose conservative pick, omit and merge_deep helpers.
