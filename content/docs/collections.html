Collections

Strut keeps common collection operations in the language/runtime surface so ordinary data work does not require a dependency stack.

Dynamic arrays

int[] values := [1, 2, 3];
values.push(4);
print(values[0]);

Maps

map<string, int> counts := [
    "users": 10,
    "jobs": 4
];

counts.insert("workers", 2);

Map and filter

squares := values.map((x) => x * x);
even := values.filter((x) => x % 2 == 0);

Reduce

sum := values.reduce(0, (total, x) => total + x);

Queries

has_large := values.any((x) => x > 100);
all_positive := values.all((x) => x > 0);
first_even := values.find((x) => x % 2 == 0);
count_even := values.count((x) => x % 2 == 0);

Grouping helpers

by_role := users.count_by((user) => user.role);
by_id := users.index_by((user) => user.id);
groups := users.partition((user) => user.active);
