Collections

Dynamic arrays, fixed arrays and maps are implemented. Higher-order helpers such as map, filter, reduce, count_by and partition remain later checkpoints.

int[] values := [1, 2, 3];
values.push(4);
values.pop();

int[3] fixed := [1, 2, 3];

map<string, int> scores := [
    "alice": 10,
    "bob": 20
];

Indexing is bounds checked. Map iteration is deterministic in the current runtime representation.
