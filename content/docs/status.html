Implementation status

The docs describe both the language contract and the compiler as it exists today. This page is the quick reference for what has actually reached the implementation and regression suite.

Implemented through CP76

  • Portable C++20/CMake bootstrap, with Linux, macOS, and Windows treated as first-class architectural targets.
  • Lexer, parser, semantic analysis, typed source-mapped IR, and native executable generation through a backend boundary.
  • Primitive and fixed-width types, ordinary type aliases, arrays, maps, strings, JSONIC-backed json, structs, generics, enums, switch, and exhaustive enum match.
  • First-class functions, generic and inferred lambdas, fixed-precedence operator overloading, lambda operator definitions, and overloadable assignment/initialisation.
  • No-GC memory model prototype with reference-counted ptr<T>, non-owning ref<T>, weak_ptr<T>, and explicit unsafe/raw_ptr<T>; raw pointers support raw->member.
  • Checked error signatures, throw, typed try/catch, and catch-all handling.
  • Filesystem operations, streams, environment access, clocks, sleeping, argv-safe external process execution, and explicit shell execution.
  • Native threads, mutexes, typed channels, async functions/lambdas, futures, await, and a shared multithreaded executor.
  • C ABI declarations with explicit unsafe calls, plus native static/dynamic library linkage and static, dynamic, or mixed final builds.
  • Release builds request platform-appropriate optimisation, dead-code elimination, and symbol stripping.
  • strut.json package manifests, deterministic cache/lock handling, local package CLI workflows, and include <package> resolution.
  • Cross-platform TCP networking substrate, verified client TLS through libcurl, and synchronous/async HTTP client support with JSON integration.
  • Independent black-box regression coverage for compiler failures and generated native programs.

CP86 measures the first integrated one-binary application for size, startup, memory, HTTP performance, and compile time.

Current implementation milestone

CP0–CP85 are complete. Strut now has the first integrated one-binary web application path: HTTP server routing, JSON APIs, system SQLite integration, async handlers, and compile-time embedded frontend assets.
