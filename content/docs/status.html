Implementation status

The docs distinguish the Strut language contract from compiler support. Planned syntax is useful for design review, but it must not be mistaken for a feature that already compiles.

Implemented

  • Portable C++20/CMake bootstrap project.
  • strut --help and strut --version, including JSONIC-backed machine-readable version metadata.
  • Independent black-box regression harness with self-certification.
  • Cross-platform architecture contract for Linux, macOS, and Windows.
  • .p/.h source loading, source spans, comments, identifiers, keywords, punctuation and the fixed lexical operator spellings.
  • Primitive lexer support for decimal integers, floating/exponent literals, escaped strings, booleans and null, with malformed-literal diagnostics.

Next

CP10 is complete: the parser now accepts inferred and typed := declarations, ordinary = assignment, const declarations, and mandatory semicolons. CP11 adds the full expression/operator grammar. Later language pages currently describe planned behaviour.
