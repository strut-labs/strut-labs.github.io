Linking & FFI

Strut treats static and dynamic linking as equally legitimate deployment choices. A single self-contained executable is useful, but applications should not be forced to absorb every library into every binary.

Link modes

strut make --static
strut make --dynamic

Mixed linking

Projects will be able to statically link some dependencies while dynamically linking others.

http = static
sqlite = dynamic

Native libraries

The FFI/linker layer is planned to support conventional static and dynamic native libraries across Linux, macOS, and Windows.

libexample.a
libexample.so
libexample.dylib
example.dll

Only JSONIC and libcurl are pre-approved embedded third-party dependencies. Additional vendored libraries require an explicit design decision.
