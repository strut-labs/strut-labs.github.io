Functions & lambdas

Functions are now first-class values: they can be assigned, passed and returned.

function add(int a, int b) -> int {
    return a + b;
}

function<(int, int) -> int> f := add;

generic_max := (T x, T y) => {
    if (x > y) { return x; }
    return y;
};

-> void remains explicit. Void functions may use return;. Lambdas capture outer values by value by default so escaping closures do not borrow dead stack storage implicitly.
