JSON

json is implemented as a built-in type backed by JSONIC. Object braces deliberately mean JSON rather than inferring a homogeneous map.

payload := {
    "name": "Nick",
    "active": true,
    "roles": ["admin"]
};

parsed := json.parse("{\"answer\":42}");
text := json.stringify(parsed);
pretty := json.pretty(parsed);

Navigation and structural equality are implemented. json.encode(value) is available as the first typed-conversion direction; generic typed decode is reserved for later conversion work once the struct/generic machinery is mature enough.
