Concurrency

Strut is designed for real multithreaded concurrency rather than a single-threaded event-loop model. Explicit threads, mutexes, channels, and async execution are staged later in the implementation roadmap.

Thread shape

worker := thread(work, arg1, arg2);
worker.join();

Lambda thread

worker := thread(() => {
    do_work();
});

Mutex locking

mutex mtx;

mtx.lock(() => {
    counter++;
});

Concurrency syntax is part of the language design; implementation follows the current IO/runtime checkpoints.
