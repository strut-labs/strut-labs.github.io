Async

Async/await is intended to provide structured asynchronous code backed by a genuinely multithreaded runtime where useful.

Async functions

async function fetch_user(int id) -> User {
    response := await http.get("/users/" + to_string(id));
    return await response.json<User>();
}

Async lambdas

handler := async (request) => {
    return await process(request);
};

Single-expression async lambda

load := async (url) => await http.get(url);

The parser recognises async lambda syntax, while the runtime executor arrives in a later concurrency phase.
