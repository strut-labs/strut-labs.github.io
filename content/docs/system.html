Processes & environment

Strut's standard library provides direct access to environment variables, clocks, sleeping, and external programs. Process execution is argv-based by default: arguments are passed as arguments rather than interpolated into a shell command.

Read environment variables

env() returns a nullable string because a variable may not exist. Use ?? when a default is appropriate.

home := env("HOME") ?? "";
print(home);

Set and remove environment variables

Mutating the current process environment can fail and uses the checked EnvironmentError contract.

function main() -> void : EnvironmentError {
    set_env("STRUT_MODE", "development");
    print(env("STRUT_MODE") ?? "missing");
    unset_env("STRUT_MODE");
    return;
}

Clocks and durations

now_ms() is monotonic and is suitable for measuring elapsed time. unix_ms() reports milliseconds since the Unix epoch. sleep_ms() pauses the current thread.

before := now_ms();
sleep_ms(25);
after := now_ms();
print(after - before);

Run an external program

exec(program, args) launches the program directly and captures stdout and stderr. It returns an exec_result containing exit_code, stdout, and stderr.

result := exec("git", ["status", "--short"]);
print(result.exit_code);
print(result.stdout);

Working directory and environment overrides

An options object can set the child's working directory and add or replace environment variables without changing the argv-safe launch model.

result := exec("tool", ["input.txt"], {
    "cwd": "/tmp/work",
    "env": {
        "MODE": "test"
    }
});

Inherited standard streams

Set inherit_stdio when the child should use the parent's terminal or redirected streams instead of being captured.

result := exec("tool", [], {
    "inherit_stdio": true
});

Shell execution is explicit

Normal exec never requires shell interpolation. When shell syntax itself is intentionally required, use the visibly different exec_shell API.

result := exec_shell("printf 'hello\n'");

Prefer exec whenever possible, especially when any argument contains external or user-provided data.
