Memory

Strut has no tracing garbage collector. Safe owning pointers are reference counted and destroy their object deterministically when the count reaches zero.

ptr<User> user;
ptr<const User> readonly;
ref<User> borrow;
ref<const User> readonly_borrow;
weak_ptr<User> weak;

unsafe {
    raw_ptr<User> raw;
}

weak_ptr<T> breaks ownership cycles. ref<T> is non-owning and non-null.
