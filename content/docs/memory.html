Memory

Strut has no tracing garbage collector. Safe owning pointers are reference counted and destroy their object deterministically when the final owner disappears.

ptr<User> user := ptr(User { ... });
ptr<const User> readonly := user;
const ptr<User> fixed_binding := user;

ref<User> borrow := ref(*user);
ref<const User> readonly_borrow := ref(*readonly);

weak_ptr<User> weak := weak(user);
ptr<User> upgraded := weak.lock();

unsafe {
    raw_ptr<User> raw := raw(user);
    *raw = other;
}

ptr<T> is safe reference-counted ownership; weak_ptr<T> is non-owning and can be upgraded with .lock(); ref<T> is non-null and non-rebindable. The first lifetime validator deliberately rejects reference escapes it cannot yet prove safe. Raw pointers and raw pointer arithmetic are confined to unsafe.

The compiler warns about obvious strong two-struct reference cycles and recommends weak back-references.
