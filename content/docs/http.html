HTTP client

The official HTTP client uses libcurl, keeps TLS certificate and hostname verification enabled, follows redirects by default, and integrates with Strut's JSON and async facilities.

GET request

function main() -> void : HttpError {
    response := http_get("https://example.com/api/status");
    print(response.status);
    print(response.body);
    return;
}

JSON response

function main() -> void : HttpError {
    body := http_get_json("https://example.com/api/user");
    print(body["name"]);
    return;
}

Custom requests

http_request accepts a method, URL, and JSON options object for headers, request bodies, timeouts, and redirect policy.

options := {
    "headers": {"Authorization": "Bearer token"},
    "body": {"name": "Nick"},
    "timeout_ms": 5000,
    "follow_redirects": true
};
response := http_request("POST", "https://example.com/api/users", options);

Async requests

pending := http_get_async("https://example.com/api/status");
response := await pending;

Streaming policy

CP76 buffers response bodies. A public streaming response API is deliberately deferred rather than exposing libcurl callbacks as language API prematurely.

TLS server note

Client TLS is backed by libcurl. OpenSSL is approved as Strut's server-side TLS backend, but HTTPS server support is not implemented yet; the plain HTTP server remains the current CP77 surface.

HTTP server

Strut's server API is built on the cross-platform TCP substrate. Routes support path parameters, query values, headers, request bodies, JSON parsing, and synchronous or async handlers.

function main() -> void : NetworkError {
    http_server app := http_server();

    app.get("/hello/:name", (http_request req) => {
        name := req.params["name"];
        return http_text("hello " + name);
    });

    app.listen("127.0.0.1", 8080);
    return;
}

Async handlers

Use get_async or post_async when a handler performs async work. The server awaits the returned Strut future before writing the response.

app.get_async("/api/items", async (http_request req) => {
    data := await load_items();
    return http_json_response(data);
});

Request data

http_request exposes method, path, headers, query, params, and body. req.json() parses the request body with JSONIC.
