Generics

Generic declarations use square brackets so they do not collide visually with instantiated types and callable signatures.

struct Box[T] {
    T value;
}

function identity[T](T value) -> T {
    return value;
}

Instantiated types continue to use angle brackets, for example Box<int> and ptr<T>. Template identifiers are uppercase. Typed lambdas may infer otherwise-undeclared uppercase type parameters:

max := (T x, T y) => x > y ? x : y;

The bootstrap C++ backend currently uses host C++ templates for instantiation. Strut's source syntax does not depend on that backend choice.
