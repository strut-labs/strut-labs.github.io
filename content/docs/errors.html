Errors

Checked error signatures and throw are implemented. A function lists the checked errors it may propagate after its return type.

function load(string path) -> Config : IOError {
    throw IOError("failed to read config");
}

function parse(string path) -> Config : (IOError, ParseError) {
    return load(path);
}

Calling a function that may throw a checked error requires the current function to declare that error until it is handled. Typed try/catch handling is the next checkpoint.
