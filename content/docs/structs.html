Structs

Fields, construction, inline methods, out-of-struct method definitions, abstract contracts and restricted inheritance are implemented.

struct Printable {
    function text() -> string;
}

struct Named {
    string name;
}

struct User : Named, Printable {
    function text() -> string {
        return name;
    }
}

A struct with unsatisfied method declarations is abstract and cannot be instantiated. Strut currently permits one data-bearing base plus additional contract-style bases; multiple data-bearing bases are rejected to avoid C++-style diamond/layout complexity.
