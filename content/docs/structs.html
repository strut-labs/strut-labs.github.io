Structs

Fields, construction, inline methods and out-of-struct method definitions are implemented.

struct User {
    int id;
    string name;
    function display_name() -> string;
}

function User::display_name() -> string {
    return name;
}

user := User { id: 7, name: "Nick" };

Fields and methods are public by default and field layout follows source declaration order. Abstract contracts and inheritance remain later design/implementation work.
